**Content Freshness Signals:**
- Add `dateModified` to all Article schema (AI platforms favor recently updated content)
- Display "Last updated: [date]" visibly on all pillar pages and key blog posts
- Commit to quarterly updates on pillar pages (at minimum)

**Author Authority:**
- Create detailed author profile pages with credentials, publications, LinkedIn
- Use `Person` schema with `jobTitle`, `worksFor`, `sameAs`
- Build author citations on external platforms (guest posts, conference talks, LinkedIn articles)

**Site Architecture for AI Crawling:**
- Flat URL structure: /guide/, /blog/, /features/
- Internal links use descriptive anchor text (not "click here")
- Breadcrumb navigation with BreadcrumbList schema on every page
- Table of contents on long-form content (pillar pages, 2000+ word posts)

**Performance:**
- Target sub-2-second load time (AI crawlers have timeout limits)
- Server-side rendering or static generation (not client-only React for public content)
- Clean HTML output (minimize JavaScript-dependent content for crawlability)
